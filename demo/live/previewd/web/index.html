perch live demo

a disposable inbox for trying perch and IMAP/SMTP

Shared, throwaway, no signup. You get a random address on tryperch.mxraven.com that can receive mail from anywhere for 60 minutes. You can send only to other addresses in the demo domain.

Don't send anything private. The demo is reset regularly and may be restarted without notice.

What works: receive mail from anywhere at your demo address, search and fetch it with the perch CLI or IMAP, and send to other @tryperch.mxraven.com addresses. Outbound mail to the public internet is rejected by an mxRaven submission rule. Try sending to yourself first.
web terminal · perch is preconfigured connecting
The terminal runs inside a disposable container. You can create files under /tmp and use them as attachments, for example: echo hello > /tmp/note.txt, then perch mail send --to "$PERCH_IMAP_USER" --subject hi --body hi --attach /tmp/note.txt.
