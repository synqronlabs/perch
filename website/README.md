# perch documentation site

The documentation site is built with [Hugo](https://gohugo.io) and the
[Hugo Book](https://github.com/alex-shpak/hugo-book) theme. The theme is pinned
as a Hugo Module in `go.mod`.

## Requirements

- Go (for Hugo Modules)
- Hugo 0.158 or newer

## Local development

```sh
# Regenerate manpages and the CLI reference.
make docs

# Serve with live reload.
hugo server --source website --minify

# Production build.
make website
```

The generated output is written to `website/public` and is ignored by git.

## Generated content

Do not edit these by hand:

- `man/*.1`
- `website/content/docs/cli/*.md`

They are generated by `cmd/gen-docs` from the `urfave/cli` command tree:

```sh
make docs
```

`make docs-check` regenerates them and fails if the working tree changes. CI
runs this check, so command/flag changes must include regenerated docs.

## Hand-written content

Everything else under `website/content` is maintained by hand. Use Markdown
links with `.md` destinations (for example `../configuration.md`); the theme's
portable-link checking validates them because `BookPortableLinks = 'error'`.

## Deployment

The `Website` workflow builds the site and deploys it to GitHub Pages on pushes
to `main` that touch the site or generated documentation.

Before the first deployment, enable GitHub Pages in the repository:

1. **Settings → Pages**
2. **Build and deployment → Source**: **GitHub Actions**

The site is configured for `https://perch.mxraven.com/`. The custom domain is
declared in `website/static/CNAME`, which Hugo copies into the published site
for GitHub Pages.
